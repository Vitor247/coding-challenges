## Problema

https://leetcode.com/problems/two-sum/

## Descrição do Problema

```
You are given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

Example:

Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].
```

## Solução

A solução mais direta é a força bruta: percorrer o array com dois loops aninhados, testando todas as combinações de pares até encontrar dois números cuja soma seja igual a `target`. Essa abordagem funciona, mas tem complexidade de tempo O(N²), já que para cada elemento percorremos novamente todo o restante do array. A complexidade de espaço, por outro lado, é O(1), pois não usamos nenhuma estrutura auxiliar.

Para otimizar, podemos trocar espaço por tempo usando um `HashMap`. A ideia é percorrer o array uma única vez e, para cada número, calcular o `complemento` (a diferença entre `target` e o número atual). Antes de inserir o número atual no mapa, verificamos se esse complemento já foi visto anteriormente. Se sim, já temos o par que soma `target` e podemos retornar os índices imediatamente. Se não, guardamos o número atual no mapa junto com seu índice e seguimos para o próximo. Assim, cada elemento é visitado apenas uma vez, reduzindo o tempo para O(N).

## Código

- Linguagem: Java

Força Bruta:

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int result[] = new int[2];

        for(int i = 0; i < nums.length; i++) {
            for(int j = i + 1; j < nums.length; j++) {
                if(nums[i] + nums[j] == target) {
                    result[0] = i;
                    result[1] = j;
                    return result;
                }
            }
        }
        return result;
    }
}
```

Hash Map (Otimizada):

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];

            if (map.containsKey(complement)) {
                return new int[] { map.get(complement), i };
            }

            map.put(nums[i], i);
        }

        return new int[0];
    }
}
```

**_Análise de Complexidade_**

Força Bruta:
- _Complexidade de Tempo_: O(N²)
- _Complexidade de Espaço_: O(1)

Hash Map (Otimizada):
- _Complexidade de Tempo_: O(N)
- _Complexidade de Espaço_: O(N)
