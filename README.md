# coding challenges

Uma jornada resolvendo problemas de lógica, estrutura de dados e algoritmos.

Este repositório está organizado (por enquanto) em uma parte principal, com mais módulos chegando conforme o projeto cresce.

> Nos próximos passos, o repositório também vai incluir desafios do HackerRank e do Beecrowd, desafios propostos por canais como o [Codecon](https://www.youtube.com/@codecondev), e uma seção dedicada a desafios de entrevistas técnicas.

#

Cada solução inclui:
- O enunciado (ou link para o problema/desafio original)
- A ideia usada para resolver
- A complexidade de tempo e espaço (quando aplicável)
- O código comentado
